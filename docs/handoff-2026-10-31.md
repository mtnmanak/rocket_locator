## Gotchas found this session

- **agy quota.** All `gemini-4-argon-high` calls returned exit 10 ("Individual quota reached"). The fallback (retry once, then
  Codex) worked; expect less model diversity until the quota resets.
- **Codex's sandbox can't run `gh`** (CLI configuration access denied). Run GitHub checks yourself and hand the results over as a file.
- **Audit tests run without touching tracked build files**, through init scripts:
  `./gradlew --no-configuration-cache -I .claude/audit-2026-10-31/<dir>/<script>.init.gradle …`. These audit commands pass
  `--no-configuration-cache` alongside the init script.
- **`git worktree remove` fails on long paths** under the scratchpad ("Filename too long"). Use PowerShell
  `Remove-Item -LiteralPath '\\?\<path>' -Recurse`, then `git worktree prune`.
- Working-tree line endings are mixed (some docs CRLF, most tracked files LF); the index is LF (`autocrlf`). Git's "CRLF will be replaced
  by LF" warning on edited docs is normal and doesn't change what is committed.
- The earlier gotchas still apply: `task --help` starts a real Codex task; `JAVA_HOME` must be exported; `docs/brand/** -text`;
  release-signed installs only.
