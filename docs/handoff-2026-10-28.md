## Gotchas found this session

- **`codex-companion.mjs task --help` is not a help flag.** It starts a real Codex task. It was harmless here (read-only, no
  changes), but the task's real options are in the script's usage line: `task [--background] [--write]
  [--resume-last|--resume|--fresh] [--model <model|spark>] [--effort <none|minimal|low|medium|high|xhigh>]`.
- `agy-delegate` defaults to the `flash` tier and a 5-minute timeout. Pass `--model gemini-4-argon-high` and a longer
  `--timeout` for full-file reads.
- The gotchas from 27 Oct still apply: `JAVA_HOME` must be exported; `docs/brand/** -text`; release-signed installs only on
  Eric's phone; rocketryforum.com blocks automated fetches.
