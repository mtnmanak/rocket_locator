## Gotchas found this session

- **AGP 9:** built-in Kotlin (no `kotlin-android` plugin, no `kotlinOptions`); `resValues` is off by default; configure JUnit 5
  through `android.testOptions.unitTests.all { }`, because a top-level `tasks.withType<Test>` block was missed under the
  configuration cache. Init scripts that add Kotlin test sources must use `sourceSets.test.kotlin.srcDir`.
- **Current AndroidX needs compileSdk 37**, even with targetSdk 36. Compose Material3 no longer brings `material-icons-core`; it is
  an explicit dependency, frozen at 1.7.8.
- **Don't copy `build/` folders between machines.** The incremental caches hold absolute paths; run `./gradlew clean` first.
- `cat $files` with an empty list waits on stdin and hangs the shell; guard it, or redirect `< /dev/null`.
- Earlier gotchas still apply (31 Oct handoff): Codex can't run `gh`; long-path worktree removal; mixed line endings.
