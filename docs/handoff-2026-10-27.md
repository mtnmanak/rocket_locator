## Gotchas found this session

- **`JAVA_HOME` isn't set** in the agent shell: use `export JAVA_HOME=/c/Users/Eric/tools/jdk17` before
  `./gradlew`. A Gradle run without it fails and leaves stale test-result XML that looks like a pass.
- **`core.autocrlf=true`** rewrote `docs/brand/tokens.json` to CRLF on checkout and broke `sync-brand --verify`.
  Fixed with `.gitattributes` (`docs/brand/** -text`). If another vendored path is added, add it there too.
- **Installing on Eric's phone:** it runs the release-signed app. A debug APK can't install over it without an
  uninstall (which wipes the saved rocket position). Build `:app:assembleRelease` (uses local
  `keystore.properties`) and `adb install -r` instead. The phone currently has release 0.03.
- **rocketryforum.com** blocks automated fetches (403). Read it through Claude in Chrome if needed.
