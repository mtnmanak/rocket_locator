# Security policy

Please report vulnerabilities privately using GitHub's **Report a vulnerability**:
[Submit a private report](https://github.com/mtnmanak/rocket_locator/security/advisories/new).
Private vulnerability reporting is enabled for this repository.
Please do not report security issues in public Issues or discussions.

Scope includes the Android app and its release signing and CI pipeline.
Include affected versions, reproduction steps, and the potential impact.
Do not include signing keys, passwords, or other secrets in your report.
There is no bug bounty or paid reward program.
Responses and fixes are best effort from a solo maintainer; no response deadline is guaranteed.
